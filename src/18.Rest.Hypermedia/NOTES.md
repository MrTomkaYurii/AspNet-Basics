# 18. REST: гіпермедіа (HATEOAS)

## Що демонструємо

Відповіді з полем `_links`, що містить URL наступних можливих дій. Набір
посилань **залежить від стану ресурсу** (порожній кошик не пропонує оформлення).

## Ключові концепції

### Модель зрілості Річардсона

| Рівень | Що є | Приклад |
|---|---|---|
| **0** | один URL, один метод (зазвичай POST), RPC поверх HTTP | SOAP, `/api` з `{"method": "..."}` |
| **1** | багато ресурсів (URI), але метод один | `/getProduct`, `/deleteProduct` |
| **2** | ресурси + дієслова HTTP + коди відповідей | більшість «REST API» (приклади 14–17) |
| **3** | рівень 2 + **гіпермедіа**: клієнт іде за посиланнями | цей приклад |

Більшість промислових API живуть на рівні 2 — і це нормально. Рівень 3 корисний
там, де робочі процеси складні й змінюються (замовлення, документообіг,
платежі): сервер керує тим, які переходи дозволені.

### Що дає HATEOAS
- Клієнт не «зашиває» структуру URL — менше зв'язності.
- Дозволені дії визначає сервер за станом → бізнес-правила в одному місці.
- API можна еволюціонувати (змінити URL, прибрати дію) без оновлення клієнтів.

### Ціна
- Складніші клієнт і сервер.
- Більший обсяг відповіді.
- Потрібен погоджений формат гіпермедіа.

### Формати гіпермедіа
- **HAL** — `_links`, `_embedded` (використано спрощений варіант тут).
- **JSON:API** — `links`, `relationships`, сувора специфікація.
- **Siren**, **Collection+JSON**, **Hydra** — з описом дій і полів форм.

### Практична порада
Навіть без повного HATEOAS корисно додавати `self`-посилання й `next`/`prev` для
колекцій (приклад 16). Це дешево й одразу зменшує зв'язність.

## Спробуйте самі

1. `GET /` — точка входу. Далі рухайтесь **тільки** за `_links`, не вгадуючи URL.
2. `GET /products` → у кожного елемента є `_links.self`; перейдіть за одним.
3. `GET /products/1` → `_links`: `self`, `addToCart`.
4. `GET /cart` (порожній) → у `_links` **немає** `checkout`.
5. `POST /cart/items` `{ "productId": 1 }` → тепер у `_links` з'явився `checkout`.
6. `POST /cart/checkout` → підтвердження. `GET /cart` знову порожній, `checkout` зник.
